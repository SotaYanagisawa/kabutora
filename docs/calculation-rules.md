# Calculation rules

- 金額・数量・株価は文字列で保持し、Decimal.jsで演算する。
- 平均原価法では、買付時に数量と総原価を加算し、売却時に売却直前の平均原価で払出原価を配賦する。
- `TRANSFER_IN` は数量と取得原価だけを増加させ、現金を動かさない。
- 入金は現金と純入金を増加させる。買付は現金を減らし、売却は現金を増やす。
- 実現損益 = 売却代金 − 配賦取得原価。
- 含み損益 = 現在評価額 − 残存取得原価。
- 分割は元取引を書き換えず、数量へ比率を乗じ、単価を同じ比率で除す。
- 画面上の最新価格には、取引所、セッション、基準時刻、鮮度、プロバイダを付与する。
